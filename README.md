# Blinkit Support AI 🤖

An AI-powered customer support chatbot inspired by Blinkit, designed to make online grocery shopping support easier, faster, and more convenient.

🚀 **Live Demo:** [Visit Blinkit Support AI](https://blinkit-support-ai.vercel.app/)

Blinkit Support AI helps customers track their orders, search for products, request refunds, register complaints, and connect with human support through a simple conversational interface.

## ✨ Features

- **Order Tracking:** Check order status and view order details.
- **Product Search:** Search for products and check their prices and availability.
- **Refund Management:** Check refund eligibility and submit refund requests.
- **Customer Complaints:** Register complaints and customer support queries.
- **Human Support:** Escalate issues to a human support agent.
- **AI Chatbot:** Get assistance through an AI-powered conversational assistant.

## 🚀 Getting Started

To run the project locally:

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Configure the required environment variables in a `.env` file.
4. Start the development server using `npm run dev`.

**Note:** Never upload your `.env` file or API keys to GitHub.
