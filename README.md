# Blinkit Support AI 🤖

An AI-powered customer support chatbot designed to make online grocery shopping support easier and faster.

Blinkit Support AI helps customers track orders, find products, request refunds and get assistance through a simple conversational interface.

## ✨ Features

- **Order Tracking:** Check order status and view order details.
- **Product Search:** Find available products with prices and stock information.
- **Refund Management:** Check refund eligibility and submit refund requests.
- **Customer Complaints:** Register customer issues and support queries.
- **Human Support:** Escalate customer issues to a human support agent.
- **AI Chatbot:** Get responses through a conversational AI assistant.
