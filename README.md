# Blinkit Support AI 🤖

An AI-powered customer support chatbot inspired by Blinkit that makes grocery shopping support faster and easier.

🔗 **Live demo:** https://blinkit-support-ai.vercel.app/

### ✨ Features
- **Order Tracking:** Check order status and details.
- **Product Search:** Find products, prices, and availability.
- **Refund Management:** Check eligibility and request refunds.
- **Customer Complaints:** Register complaints and queries.
- **Human Support:** Connect with support agents.
- **AI Chatbot:** Get instant AI-powered assistance.
- Replies in English, Hindi and Hinglish

### 🛠️ Tech Stack
React, TypeScript, CSS, Node.js, MongoDB, Google Gemini AI, Vite, and Vercel.

### 🌟 Highlights
- Interactive chat interface.
- AI-powered customer assistance.
- Easy order and refund management.
- Responsive and user-friendly design.
- Organized frontend and backend.

### 🚀 Getting Started
1. Clone the repository.
2. Run `npm install`.
3. Configure environment variables in `.env`.
4. Start using `npm run dev`.

**Note:** Never upload your `.env` file or API keys to GitHub.

### 👩‍💻 About
Blinkit Support AI is an independent, Blinkit-inspired project demonstrating AI integration, modern web development, and conversational customer support solutions for online grocery shopping.
